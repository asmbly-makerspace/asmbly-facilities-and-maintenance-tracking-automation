## Implementation details

### layer: `layers/common/python/common/brand.py`

No imports at all; the standard library would be allowed. Module docstring: what it holds,
which pages use it and through which markers, that a change here reaches both pages on
the next deploy (a new layer version, which updates every function that uses the common
layer), and that it must stay standard-library only, because the photo page function has
this layer and no other.

```python
BRAND_TOKENS_MARKER = "/* __BRAND_TOKENS__ */"
ASMBLY_LOGO_MARKER = "<!-- __ASMBLY_LOGO__ -->"

# The shared design tokens, as CSS declarations for a page's :root block. The first line has
# no indentation (the marker it replaces is indented), later lines four spaces, no trailing
# newline.
BRAND_TOKENS = """/* Shared brand tokens, from layers/common/python/common/brand.py. */

    --space-1: 0.25rem;
    --space-2: 0.5rem;
    --space-3: 0.75rem;

    --border-width: 1px;

# The official Asmbly logo (asmbly-makerspace/asmbly-classes,
# app/src/lib/components/logo.svelte at 9a534a6c538df1e602fead183e30d93d97c247b4), inline.
# Its colour comes from the page's CSS (.logo { fill: currentColor; }).
ASMBLY_LOGO = """<svg class="logo" role="img" aria-label="Asmbly Makerspace" viewBox="0 0 443.61 122.16" focusable="false">
      <path d="…"/>   # the 17 <path> lines, copied byte for byte from the stage page.html
      …
    </svg>"""


def fill_brand(page: str) -> str:
    """`page` with BRAND_TOKENS in place of its token marker and ASMBLY_LOGO in place of its logo marker.

    The token marker must appear exactly once; the logo marker at most once (a page may
    have no logo). Raises ValueError otherwise, naming the marker and the count. Reads
    BRAND_TOKENS and ASMBLY_LOGO when called, so a changed value reaches every page that
    fills itself afterwards.
    """
```

- Values: every token value above is copied from the stage `page.html` files. The test
  `test_shared_tokens_match_both_pages` (below) is what proves they match, not this listing.
- `ASMBLY_LOGO`: the opening tag, then the 17 `<path d="…"/>` lines copied from
  `functions/classes/class_photo_upload_page/page.html` lines 259–275 (each indented six
  spaces), then `    </svg>`. With the photo page's marker indented four spaces, phase 2
  serves that page's logo byte for byte as it is today.
- The `ValueError` messages: `"page must have exactly one /* __BRAND_TOKENS__ */ marker,
  found N"` and `"page must have at most one <!-- __ASMBLY_LOGO__ --> marker, found N"`.
  They hold no page content.
- Signature types: `fill_brand(page: str) -> str`; module constants are `str`.

No page imports the module in this phase. Adding it publishes a new layer version on the
next stage deploy, with no change in behavior.

### lambda (tests): the capture command

Run it once from the repository root, before writing the pin tests. It reads the pages
from the commit, not the working tree, so the pins are `stage` as it was before this plan:

```bash
.venv/bin/python - <<'EOF'
import json, pathlib, re, subprocess
from tests import page_style

PAGES = {
    "functions/ceramics/kiln_dropoff_recent_entries_viewer": re.compile(r"<style>(.*?)</style>", re.S),
    "functions/classes/class_photo_upload_page": re.compile(r'<style nonce="__CSP_NONCE__">(.*?)</style>', re.S),
}
for folder, block in PAGES.items():
    html = subprocess.run(["git", "show", f"6fd11c9:{folder}/page.html"],
                          capture_output=True, text=True, check=True).stdout
    sheet = page_style.Stylesheet.from_page(html, block)
    out = pathlib.Path(folder, "tests", "fixtures")
    (out / "pinned_tokens.json").write_text(
        json.dumps(sheet.tokens(), indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
    rules = [line.rstrip() for line in sheet.rules_after_root().splitlines() if line.strip()]
    (out / "pinned_rules.css").write_text("\n".join(rules) + "\n", encoding="utf-8")
    print(folder, len(sheet.tokens()), "tokens,", len(rules), "rule lines")
EOF
```

Expected: 54 tokens for the kiln page, 79 for the photo page.

### lambda (tests): the pins in each page's test file

Each test file gets a helper and two tests, next to its other style tests. They compare
what the page **serves**, not what `page.html` holds.

- **Kiln:** for each page in `_pages()` (empty, tasks, error), the stylesheet is
  `page_style.Stylesheet.from_page(page, STYLE_BLOCK)`.
- **Photo:** the stylesheet comes from `_call(_event())["body"]`, read with
  `re.compile(r'<style nonce="[A-Za-z0-9_-]+">(.*?)</style>', re.S)`, because the nonce
  has been filled in.
- `_pinned_rules(sheet)` normalizes the same way as the capture command: lines
  right-stripped, blank lines dropped.

| Test | Proves |
| --- | --- |
| `test_served_tokens_are_the_stage_tokens` | The served `:root` tokens, as a dict, equal `fixtures/pinned_tokens.json`, and the `:root` block declares `color-scheme: light`. Story criterion 3: "the served token names and values … are the same as before (a test pins them)". |
| `test_served_rules_are_the_stage_rules` | Every rule after `:root`, normalized, equals `fixtures/pinned_rules.css`. Story criterion 3: "… and the CSS rules are the same as before". |

Each docstring says that the fixtures are `stage` 6fd11c9 from before story #138, and
that a deliberate change to the page's look regenerates them with the capture command
in `.implementation_plans/shared-brand-tokens/phase-1-brand-module-and-stage-pins.md`.
In phase 2 that path also goes in the function README.

### lambda (tests): `tests/test_shared_brand.py`

Module docstring: tests that span both pages and `common.brand`. Imports `common.brand`,
`tests.page_style`, and both pages' `lambda_function` modules (the photo page's as
`photo`, the kiln's as `kiln`).

- **Helpers.**
  - `_served_sheets() -> dict[str, page_style.Stylesheet]` holds the served shells:
    kiln `kiln.PAGE_TEMPLATE`, read with `<style>(.*?)</style>`; photo `photo._template()`,
    read with `<style nonce="__CSP_NONCE__">(.*?)</style>`.
  - `_brand_tokens() -> dict[str, str]` is
    `page_style.Stylesheet(":root { " + brand.BRAND_TOKENS + " }").tokens()`.
- `PAGE_ROLE_TOKENS = {"--page-bg", "--text", "--glyph-error"}`, with a comment: the same
  on both pages, kept by each page as its own (README Decision 4).
- `PINNED` maps each page to its `pinned_tokens.json`, loaded with `json.loads`.

| Test | Proves |
| --- | --- |
| `test_shared_tokens_match_both_pages` | Every token in `BRAND_TOKENS` is served by both pages with the same value: `served[name] == value` for each of the 32. Proves the module holds what the pages serve, before and after phase 2. |
| `test_shared_tokens_are_the_story_list` | Every name that both pinned fixtures hold with the same value is either in `BRAND_TOKENS` or in `PAGE_ROLE_TOKENS`, and the two sets are disjoint. `len(_brand_tokens()) == 32`, with none defined twice in `BRAND_TOKENS`. Pins Decision 4. |
| `test_logo_matches_both_pages` | `page_style.logo_problems(page_style.find_logo(brand.ASMBLY_LOGO)) == []`. For each served shell, `" ".join(find_logo(shell).split())` equals the same normalization of `find_logo(brand.ASMBLY_LOGO)`. |

### layer (tests): `layers/common/tests/test_brand.py`

The same `sys.path` preamble as `test_aws.py`, then `from common import brand`. Uses
pytest and the standard library only, with no `tests.page_style`, so the layer's tests
stand alone.

| Test | Proves |
| --- | --- |
| `test_fill_brand_replaces_both_markers` | A page with each marker once comes back with `BRAND_TOKENS` and `ASMBLY_LOGO` in their places and neither marker left. |
| `test_fill_brand_needs_exactly_one_token_marker` | 0 and 2 token markers raise `ValueError` matching `found 0` and `found 2`. |
| `test_fill_brand_allows_no_logo_but_not_two` | No logo marker: the tokens are filled and no `<svg` is added. Two logo markers: `ValueError` matching `found 2`. |
| `test_fill_brand_reads_the_current_values` | After `monkeypatch.setattr(brand, "BRAND_TOKENS", "--x: 1px;")`, `fill_brand` puts `--x: 1px;` in. This is the property phase 2's both-pages test relies on. |
| `test_brand_tokens_are_declarations` | With `/* … */` comments removed, the text splits on `;` into exactly 32 `--name: value` declarations, with no name twice. |
| `test_shared_text_cannot_leave_its_place` | `BRAND_TOKENS` has no `{`, `}`, `<` or `>`. Neither constant contains `__`, so neither can hold a page's marker (`__BRAND_TOKENS__`, `__ASMBLY_LOGO__`, `__CSP_NONCE__`, `__PAGE_CONFIG__`, `__MAIN_CONTENT__`, `__RELOAD_TEXT__`). |

| `test_importing_brand_loads_no_third_party_module` | `subprocess.run([sys.executable, "-I", "-c", code], check=True, capture_output=True, text=True)`, where `code` puts `layers/common/python` (absolute) on `sys.path`, imports `common.brand`, and prints whether `boto3`, `botocore` or `requests` is in `sys.modules`. ## Acceptance criteria

1. `layers/common/python/common/brand.py` defines `BRAND_TOKENS` (32 tokens),
   `ASMBLY_LOGO` (the 17-path logo), both markers and `fill_brand`, and imports nothing
   outside the standard library. That last part is story criterion 6, checked by
   `test_brand_imports_only_the_standard_library`.
2. Every shared token's value in `BRAND_TOKENS` equals what both pages serve today, and
   `ASMBLY_LOGO` equals both pages' logos once whitespace is collapsed. Checked by
   `test_shared_tokens_match_both_pages` and `test_logo_matches_both_pages`.
3. Each page has `pinned_tokens.json` and `pinned_rules.css` generated from `stage`
   6fd11c9 by the capture command, and the pin tests pass on the unchanged pages. This is
   the pinning half of story criterion 3.
4. No `page.html`, `lambda_function.py`, template or config changes. `git diff --stat
   origin/stage` lists only the files in this document.
